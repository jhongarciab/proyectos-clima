# Proyectos de clima

Repositorio académico para mini proyectos de **Física del clima y cambio climático**.

## Contenido
- `proyecto 1/`: análisis climático con 10 años de datos diarios (temperatura, precipitación, humedad), comparación de fuentes, anomalías, histogramas y Fourier.
- `proyecto 2/`: atmósfera estándar ISA, climatologías regionales ERA5, capas para QGIS, comparación geostrófica en niveles de presión y perfil vertical de temperatura frente a ISA.
